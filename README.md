# 樂園大亨

致敬《模擬樂園 1》（RollerCoaster Tycoon）的單機版網頁遊樂園經營遊戲。單一 `index.html`，直接用瀏覽器開啟即可遊玩。

## 功能
- 等角視角地圖、道路鋪設、3 個關卡（不同地形與目標）
- 9 種遊樂設施（含水上設施）、7 種商店、長椅／垃圾桶／路燈與景觀
- 雲霄飛車軌道建造：直線、彎道、坡道、鏈條上坡、陡坡，物理模擬計算興奮度／刺激度／噁心度，可自動接回車站
- 遊客 AI：飢餓、口渴、如廁、體力、噁心、垃圾、嘔吐、破壞公物、想法
- 員工：清潔工、技工、警衛、藝人
- 經營：門票、票價、貸款、每月收支、設施故障、樂園評價
- 研發系統：經費與方向設定，解鎖新設施
- 瀏覽器本機存檔（每月自動存檔）

## 操作
拖曳或 WASD／方向鍵移動畫面，滾輪或雙指縮放；R 旋轉、Esc 取消、空白鍵暫停、1/2/3 調整速度。
